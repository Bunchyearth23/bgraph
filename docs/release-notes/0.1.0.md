Diagrams as text, where you decide the layout.

Mermaid and its relatives place everything for you and leave you fighting the
engine. `bgraph` inverts that: every box says where it goes, but says it
*relative to its neighbours*, so inserting one moves what is anchored to it
instead of making you renumber coordinates.

This is the first tagged build. The language has been usable for a while; what
this tag adds is that you can get it without a Rust toolchain.

## What is in the release

| Artefact | What it is |
|---|---|
| `bgraph-<target>` | The compiler: render, check, watch, diff, explain, fmt, layout, init |
| `bgraph-lsp-<target>` | The language server, for any editor that speaks LSP |
| `bgraph-vscode-0.1.0.vsix` | VS Code — highlighting, the server, and a Markdown preview that renders ` ```bgraph ` fences |
| `bgraph-zed-0.1.0.tar.gz` | Zed — tree-sitter highlighting and the same server |
| `bgraph-typst-0.1.0.tar.gz` | A Typst package: diagrams from source written inside the document |
| `bgraph-playground-0.1.0.tar.gz` | The renderer compiled to wasm, in a page: unzip and serve |

Binaries are built for `x86_64-unknown-linux-gnu`, `aarch64-apple-darwin` and
`x86_64-pc-windows-msvc`, with default features — no rasteriser, no window.
`--features png` adds `-o diagram.png`; everything else is in the default
build.

## The language

Twenty-nine genres and `free`. A pie, a gantt, a sequence diagram, a rack
elevation and a BPMN process are all the same five statements with a different
word for what a box is:

```
type <archetype> { … }
graph { … }
style <name> [extends <name>] { … }
group <id> ["<label>"] [.class] [<where>] { … }
<word> <id> ["<label>"] <data…> [.class] [<where>] { … }
<id> <arrow> <id> ["<label>"] <data…> { … }
```

```
graph { background: #f8fafc }

style box { fill: #eef3ff stroke: #2563eb 1.5 }

node a "Alpha" .box at (0, 0)
node b "Beta"  .box right-of a gap 60

a -> b "carries"
```

`bgraph init <genre>` writes a working file for any of them.

## What it refuses to do

These are positions, not gaps waiting to be filled.

- **Guess a layout.** An archetype may arrange its own items — a pie has no
  anchors to honour — but nothing overrides a placement you wrote.
- **Ignore a name it does not know.** `fll: #fff` is an error, not a no-op.
  In a file with no compiler, a silent typo is a diagram that is quietly wrong.
- **Colour a chart by eye.** The categorical palette is checked for
  colour-vision deficiency, and past eight series it says to merge the tail
  rather than repeating a hue.
- **Emit a raster by default.** SVG and PDF need no rasteriser; anything that
  needs a bitmap can rasterise those.

## Getting it

Download the archive for your platform, put `bgraph` and `bgraph-lsp` on your
`PATH`. The editor extensions launch `bgraph-lsp` from there.

```sh
bgraph init pie > traffic.bd
bgraph traffic.bd -o traffic.svg
bgraph watch traffic.bd          # a browser preview, reloading on save
```

The reference is `docs/reference.md`, generated from the compiler's own tables
so it always describes the binary you have. `docs/manual.typ` is the manual
that teaches the language; its diagrams are drawn by the compiler it documents.
