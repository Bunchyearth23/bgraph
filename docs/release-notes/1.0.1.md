# bgraph 1.0.1

29 specialised genres, plus `free`. This patch corrects nested placement,
sequence painting, cylinder labels and diagnostics. It adds no statement to the
language; the explicit `legend` blocks that landed in the same window are a
separate change.

## Corrections

- A nested group can be placed relative to a sibling inside a parent that is
  itself placed relative to another element. This no longer reports a false
  anchor cycle. Real cycles remain errors.
- Group frames paint before sequence messages in SVG, PDF and PNG. A translucent
  frame fill no longer fades the messages inside it.
- Cylinder sizing reserves the space occupied by both caps. Multiline labels
  and `block` annotations remain inside the readable body, including at low
  padding. Explicit heights remain required dimensions. A cylinder is therefore
  taller than it was, so a file that placed boxes by absolute coordinates may
  need those placements reviewed.
- An empty edge label (`""`) draws no text or background plate.
- More than one number in `font` emits a warning explaining `font-weight: 600`.
  Existing shorthand interpretation is preserved.
- A `legend` without a position emits a warning. An unknown legend anchor is
  an error instead of a silently missing key.
- A conflicting group dimension names its winning style layer, including
  `style node`, `style group`, a class or the group's own block.

## Reference and geometry JSON

The generated reference documents `via` placement and ordering, relative stops
against nodes and groups, grid cells, `legend`, and `row`/`column`. Relative
waypoints already existed; no new syntax is needed.

JSON schema version 1 gains `canvas.layout_origin: { x, y }`. Existing geometry
fields remain in canvas coordinates. Subtract this offset to recover solved
layout coordinates; group-local coordinates and bounded-grid units still have
their own conversion. This is an additive field, not a change to existing values.

## Report follow-up

The reported sequence frame at negative x is inside the canvas after the SVG's
translation. Its visible left edge is 36 units from the canvas edge; a regression
checks negative frame bounds.

One of the reported files now reports an edge label drawn over a box: the
corrected cylinder is taller, so the solved geometry moved and a label landed on
a node it did not touch before. The diagnostic is unchanged and the conflict is
real — the repair belongs to the file, by widening the gap, moving the label
with `label-offset`, or updating the absolute placement.

The reported gaps at rounded waypoints need an isolated reproduction. Text
measurement remains approximate, and carrying a font with `--embed-font` does
not recalculate layout advances: node sizes, wrapping and the solved geometry
keep the built-in estimates. Group-title plates and title bounds are the
exception — where the title names the embedded family first, that face's own
advances are used. These points are not claimed as fixed by this patch.
