# bgraph 1.0.0

29 specialised genres, plus `free`, with declared placement, a shared language
server and SVG/PDF exports. PNG remains optional (`--features png`).

## BPMN corrections from a real process diagram

The user report was drawn from an Audiospy process with four pools and six
lanes. The original reproductions, including the large contextual variants,
are retained with the implementation evidence.

- Parent frames paint before their children in SVG, PDF and PNG.
- Group `width`, `height` and `size` are enforced. A size too small for the
  contents produces a constraint diagnostic. `equal-width` and `equal-height`
  accept frames as well as nodes.
- In BPMN, a group whose direct children are all groups is a pool of lanes.
  These lanes fill the pool's inner width, respecting padding and margins.
- Start/end event warnings count sequence flows, including default and
  conditional flows. Message and association flows do not trigger them.
- Boundary-event flows leave away from their host. Automatic task ports avoid
  attached boundary events, and associations/messages do not displace sequence
  ports.
- Orthogonal routing searches from actual ports and through every waypoint;
  it does not move endpoints after obstacle avoidance. More than 60 obstacles
  no longer disables avoidance. Local channel searches still check every box
  and can retry with the complete channel grid.
- External node captions and frame titles participate in orthogonal routing.
  BPMN captions also choose clear positions near their own shape.
  `label-position: top|right|bottom|left` fixes the caption side of an event
  or gateway without requiring hand-calculated offsets.
- Fixed-width labels wrap by measured text width, including long words.
  Text that cannot fit a fixed width/height emits a diagnostic.

PDF frame titles now share the SVG title position. Accented Latin-1 text is
encoded with PDF octal escapes rather than raw UTF-8 bytes.

`style node` remains the common style layer for frames and items. Use
`style task` to size only BPMN tasks, or `style group { fill: none }` to keep
frames transparent. Explicit ports, waypoints, coordinates and label offsets
retain their meaning. Impossible routes keep a visible fallback and a warning.

## Other changes since 0.1.0

Simultaneous declared placement, deterministic constraint solving, better LSP
completion and layout snippets, CSS-order external margins, sequence frame
spacing, and a French MkDocs guide (`./docs.sh`). Background alpha uses the
existing `#RRGGBBAA` or `#RGBA` color forms.

## Artefacts

The release pipeline prepares the compiler and `bgraph-lsp`, the VS Code
`bgraph-vscode-1.0.0.vsix`, the Zed package `bgraph-zed-1.0.0.tar.gz`, the Typst
package `bgraph-typst-1.0.0.tar.gz`, and the playground
`bgraph-playground-1.0.0.tar.gz`. The same CLI/LSP serves all editor integrations.

These notes prepare version 1.0.0; local implementation evidence does not
replace the release workflow's gates. Publication is a separate action.
