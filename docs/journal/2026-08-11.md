# 2026-08-11

The dated state of the project lives in [`../INDEX.md`](../INDEX.md); this file records what a
session *did*, which the index deliberately does not.

One session, five pieces of work. The index went in first — the licence question closed, the
parked idea promoted, the two open risks each given a chantier — and everything after it was
carrying that out.

## `D-032` / `Q-005` — the licence is proprietary, and that is an answer

`D-020` said proprietary on 2026-07-31 and `Q-005` had stayed open since, because the whole
distribution half was built afterwards: the wasm playground (`W-096`), the release binaries and CI
action (`W-097`), the Markdown preview (`W-098`), the Typst plugin (`W-099`). All four work. None
of them ship.

Recorded as a **decision** rather than as a question quietly closed. The four will keep prompting
the same question from anyone who finds them, and a repository that answers "we never decided"
invites somebody to decide it by accident. Nothing in the tree changes: `LICENSE` grants nothing,
`Cargo.toml` keeps `publish = false`, and the test asserting `release.yml` creates no release and
runs no `cargo publish` is now load-bearing rather than precautionary.

## `W-103` — the treeview draws its links where the boxes are not

**What.** `charts.rs` treated `TreeKind::View` exactly like `TreeKind::Mind`: a diagonal from the
parent's right edge to the child's left. On indented rows that crosses every row between the two
and runs *behind* the boxes, because nodes are painted after polylines. So the structure of the
tree was the one thing the drawing hid.

A trunk in the gutter the indent reserves, a short elbow into each row, and the trunk stopping at
the **last** child.

**Why the last child matters.** It is not decoration. Every row between a parent and its last child
is one of its descendants, so it is indented past the trunk — which is what turns "a guide is never
behind a box" from a hope into a property. The test asserts that property over every segment
against every box rather than checking the picture, and it was **proven by reverting the fix**: it
names the guide, its coordinates and the box it crosses.

## `W-104` — `fmt --migrate`, and `X-008` retired

**What.** `bgraph fmt --migrate` folds a removed `opacity` into the alpha of every paint in its
block. `D-016` took the property out because transparency belongs to the paint; that was right, and
it was also a breaking change that had stayed open on the strength of "the message names the fix" —
which is true, and is not a migration.

Surgical rather than a reprint: the alpha digits go into the colour where it stands and the
declaration is cut out, so a comment on the same line and a column lined up by hand both survive.
The existing alpha is **multiplied** rather than replaced, because an element opacity and a paint
alpha composited.

**Two refusals, one principle** — this may move a value, it may not decide one. A block with no
colour to carry the alpha, and a named colour like `tomato`, which has no fourth channel. Both name
the line.

`--migrate` is a second mode and not a side effect of formatting: a diff that both migrated and
reflowed would be unreviewable, which is the same reason `fmt` leaves interior alignment alone.

## `W-105` — an `ortho` edge goes around the boxes, and `X-004` is retired

**What.** A\* over a grid of the only lines an orthogonal path ever turns on — a channel either
side of every box, plus the two centre lines being joined — with a price on corners.

**The corner price is the design.** Shortest alone treats every staircase of the same length as
equally good, and the one it happens to find is the ugly one.

**Determinism was the risk, not the search.** The golden test compares byte for byte and this
project has already shipped a diagram that rendered differently run to run (`W-065`, a `HashMap` in
the venn). So costs are `i64` thousandths, ties go to the state index, and there is no hash
container in the module. A test renders the same source nine times; a second declares the same
boxes in another order.

**It can decline** — past sixty boxes, or where no path exists — and then keeps the old elbow so
`check::after_layout` can report the crossing. A drawing that admits it is wrong beats a missing
edge, and `W-064`'s diagnostic did not become wrong, it became rare.

**The clearance is 16 because 8 looked wrong.** The detour ran close enough over a box that the
arrow head of the edge *terminating* on it had nowhere to sit.

**Not one checked-in SVG moved**, because no example used `ortho` — so the feature would have
shipped with nothing to look at. `examples/ortho.bd` is the worked case, and it also shows the
limit this leaves behind, recorded as `X-018`: the router avoids boxes, not other edges.

## `W-102` — `type bpmn`, the twenty-ninth genre

**What.** The core, pools and lanes as `group`s, typed event triggers, sub-processes, boundary and
intermediate events, data artefacts. `I-021` had been parked for exactly one day because BPMN is
mostly ceremony and nobody had chosen which part is useful; the choice was wide.

**Four words** — `task`, `event`, `gateway`, `data` — which is `D-023` read at its widest. Four
things carry four shapes of data, and no count of values after the label could tell a task's one
word from a gateway's one word. On the free path, per the `W-043` precedent.

**A prediction that was wrong, in the useful direction.** The tasklist said boundary events would
need a language decision: an event attached to the *edge* of a task wants an anchor on a box's
perimeter, and `D-001` has no vocabulary for one. On building it, an `attach` property naming the
host was enough — and it is declared placement like every other, since the author says which box
and where on it is a fixed rule rather than something solved. No question came back.

Three things building it turned up, all of them older than it:

- **The free path read the wrong slots.** It resolved positional values against the archetype's
  *primary* slots rather than the word the author wrote. Invisible from `W-048` until now, because
  `xy` was the only genre with a second word and `xy` is a chart, so it never came through there.
- **There was no layer for a mark inside a shape.** Every polyline in the engine is drawn before
  the boxes, so a gateway's cross rendered behind an opaque diamond — which looks exactly like
  "the glyph code never ran". `Polyline::over` splits the pass in both writers.
- **The router needed a rule about boundary events.** One sits *on* a task, so every flow out of it
  starts inside a box. Its host is not an obstacle for it and not a crossing to report;
  `layout::endpoint_of` is where the router and the validator now agree about that.

**The glyphs are line segments, never a Unicode character.** `✉` is whatever the reader's font says
it is, and for a notation whose whole value is an unambiguous mark that is not a detail. What is
deliberately not there: a marker so fussy it stops reading at sixteen pixels. A gear at that size
is a smudge, so a service task gets a ring of spokes.

Said rather than left as a gap: a lane's name is horizontal, because rotated text is a change to
both writers and their bounds; and a message flow has no circle at its source.

## The catch-up — and the defect it found, again

The repository was then brought up to the language, the way `W-101` did on the tenth. It found the
same *kind* of thing, in the same place.

**Go-to-definition looked for `node` and nothing else.** It searched the literal keywords `node`
and `style`, so in the twenty-eight genres with a word of their own the jump silently did nothing.
It never read as a bug because returning `null` is also what "no such name" looks like. Anchor
completion had the narrower version of the same fault: it asked for `def.item`, the archetype's
*first* word, so a `scatter` in an `xy` file and an `event`, a `gateway` or a `data` in a BPMN one
were invisible to it.

Both now ask the archetype for `items()`. Two guards, both proven by reverting the fix.

Also swept: the README's command list and feature prose, `docs/language.md` (a worked BPMN section,
parsed and checked by the suite like every other fence), the printed manual — its `ortho` note said
the router avoids nothing, which had become false, and its `opacity` note now names the migration —
both extension READMEs, `editors/README.md`, the genre counts in `src/init.rs` and the manual, and
three new Patterns plus three Critical Warnings in `AGENTS.md`. The manual is at edition 1.3, and a
stray Markdown `**bold**` that Typst had been rendering as literal stars since edition 1.0 is gone.
