# 2026-08-12

## The licence, corrected

`D-036` chose PolyForm Noncommercial and it lasted a few hours. The flaw was one I had written down
myself and then not weighted: Noncommercial grants a **Distribution License**, and that covers the
source. I had noted it as "the private repository is what keeps the source in, not the text", which
is true and is not the same as the source being unlicensed. The Archmagos read it and said no.

The family table settles what the alternatives are. Strict and Noncommercial have the *same*
noncommercial scope — the same `Personal Uses` and `Noncommercial Organizations` sections, word for
word. Strict simply has no `Distribution License` and no `Changes and New Works License`. So it
solves the source completely, and takes the binaries with it, and builds were supposed to circulate.

Two answers that could not both be had from one unmodified text — and the way out is not to modify
the text. PolyForm's own README says that a modified PolyForm licence must remove every mention of
"PolyForm", which would cost exactly the recognisability that made a standard text worth choosing.
So the standard text stands untouched in `LICENSE`, and the one thing it does not cover is granted
beside it in `ADDITIONAL-PERMISSION.md`: an official build may be passed on, unchanged, free, with
both files, to someone whose use is also noncommercial.

The property that makes that legitimate rather than a licence edit with a different filename is that
it **adds and never subtracts**. A copyright holder may always grant more than a licence does; the
GPL's linking exception is the same shape. A test asserts the document says so in those words, and
counts both files into every archive — because an archive carrying the licence and not the
permission has silently withdrawn the one thing the permission is for.

Two smaller findings, both from checking rather than recalling. PolyForm **Strict is not in the SPDX
list** — only Noncommercial and Small Business are — so the manifests carry
`LicenseRef-PolyForm-Strict-1.0.0`; claiming an identifier that does not exist is worse than
admitting there is none. And the confidentiality half of "no source redistribution" is not a licence
clause at all: it is the private repository, plus a sentence in the README saying that access is
personal. Copyright and confidentiality are different mechanisms and only one of them lives in
`LICENSE`.
