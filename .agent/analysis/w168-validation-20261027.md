# W-168 — validation of the 12 residual warnings (27 October 2026)

Scope: the concrete remainder of `W-168` — the twelve warnings across eight
cases — plus a replay of the 25 unchanged sources and their 75 commands.

**Outcome.** All twelve warnings are **true reports**; none is a routing,
channel or port defect in `src/ortho.rs`, and none is silenced. Nine of the
twelve are the author resolving a declared placement (a declared
`label-offset`, a declared `label-position`, a declared `size`). Two
(`04-boundary`, `04b-boundary-from-bottom`) are true but trivial — 0.28 units
of the caption's *padded* box, no ink over the box — and their cause is the
candidate set of `labels::place_captions`, which cannot see the task a
boundary event hangs on. One (`15-label-position`) is visible: the flow
strikes through the caption.

**No production file in this repository was changed.** `src/ortho.rs` is
untouched: no warning of the twelve is produced by the orthogonal router (no
fixture of the eight declares `router: ortho`). One change is *proposed* for
`src/labels.rs`, which another agent owns; it is handed over below as an
exact diff, tested in a scratch copy of the tree.

it hangs on instead of a hair above it.

**Evidence (measured in a scratch copy of the tree, `/tmp/bgraph-labels-try`,
the real repository untouched):**

- `bgraph check` on all 25 fixtures, patched vs unpatched: **the only
  difference is the two intended cases** — `04-boundary` and

  found*. The other ten warnings are untouched, and **no new warning appears
  anywhere**.
- The caption is not silenced: with the patch the caption of `e` is drawn with
  its box top at exactly the task's bottom edge (300.0 absolute, was 299.72),

  diagnostic was weakened.

Proposed regression test (for `src/tests.rs`, which is shared — **not
applied**):

```rust
#[test]
fn a_boundary_event_caption_clears_the_task_it_hangs_on() {
    let src = r#"
type bpmn { title: "boundary" }
style task { size: 176 74 }
group w "Worker" {
  task t "Lancer" service
  task r "Relance" service
  task top "Acquitter" send
  layout { place t at (0, 120)
    place r at (210, 240)
    place top at (0, 0) }
}
group m "Modules" {
  task c "Capture" service
  layout { place c at (0, 0) }
}
event e "Mort" boundary error { attach: t }
layout { place w at (0, 0)
  place m below w gap 60 align left }
t -> top
e -> r
t -> c message
"#;
    let analysis = crate::analyze_source(src);
    assert!(
        !analysis
            .diagnostics
            .iter()
            .any(|d| d.message.contains("the caption of `e`")),
        "the caption of a boundary event must not overlap the task it hangs on: {:?}",
        analysis.diagnostics
```

## 6. Proven / unproven

**Proven.** The 25 sources are unchanged; 75/75 commands succeed; the
diagnostics are byte-identical to the 20 October recording, so the twelve
warnings and their positions are the same ones; the geometry behind each
warning is reproduced from the engine and each report names the object that is

proposed `labels.rs` diff removes exactly the two trivial warnings, adds none,

**Unproven.** That the twelve pictures are *acceptable* to the user — that is
the user validation still outstanding, and no rendering of the twelve regions
has been looked at by a person. Nor has the visible strike-through of #12
been confirmed against the user's own view of the file. The 20 October
performance figure was measured on a frozen binary of that revision; the
figure above is from today's tree, so it is a same-order check, not the same
comparison.
