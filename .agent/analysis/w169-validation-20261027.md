## 2. The limitation, investigated

`include` is refused by the renderer (`src/lib.rs:258-268`) with a message that
names a Rust function an editor user cannot call. `type pie { from: "x.csv" }`
is worse: the composer resolves it (`src/compose.rs:456-571`), so the
text-only renderer ignores the file and **draws the declared slices instead** —
silently. Nothing in the WASM output says so.

Both are now handled inside the extension:

- `include` → the panel error becomes an actionable sentence naming
  `bgraph watch <file>` and the included file.
- pie/`from:` → the picture is kept (it is right about everything the buffer
  declares) and a notice band beside it says the table was not read.
- An untitled buffer has no file to watch, so the command is a placeholder
  (`bgraph watch <file>`), never a name that does not exist.
- The coupling to the compiler's wording is **pinned by a test**, so a change
  in `src/lib.rs` fails loudly instead of quietly restoring the unusable
  message.
