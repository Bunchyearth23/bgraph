**Verified against Zed's own documentation (fetched 2026-10-27).**
- `keymap.json` lives at `~/.config/zed/keymap.json` (macOS/Linux) and
  `~\AppData\Roaming\Zed\keymap.json` (Windows).
- The action that opens the **file** is `zed: open keymap file`; `zed: open
  keymap` opens the keymap **editor**. The old wording sent users to the
  editor, where the entry cannot be expressed — this was the one real
  ambiguity in the merge instructions.
- User bindings load after system bindings, so the user entry wins; and
  `ctrl-shift-v` in Zed's own default keymap is scoped to
  `Editor && extension == md` / `== svg` / tabular data, so the `.bd`-scoped
  entry shadows nothing and Markdown keeps its own preview shortcut.

## 3. The manual steps the user must do

1. Open the folder that contains the `.bd` file in Zed as a **project**
   (a window with only the file open does not expose the language task on the
   verified host).
2. Command palette → **zed: open keymap file** → open
   `~/.config/zed/keymap.json` (`~\AppData\Roaming\Zed\keymap.json` on
   Windows). If the file does not exist, create it with the array below.
3. Add this object as one element of the top-level array (keep existing
   entries, separate objects with a comma):

```json
{
  "context": "Editor && extension == bd",
  "bindings": {
    "ctrl-shift-v": ["task::Spawn", { "task_name": "bgraph: Preview" }]
  }
}
```

   A keymap with nothing else in it is exactly:

```json
[
  {
    "context": "Editor && extension == bd",
    "bindings": {
      "ctrl-shift-v": ["task::Spawn", { "task_name": "bgraph: Preview" }]
    }
  }
]
```

4. Save the file (Zed re-reads it immediately). Focus the `.bd` file and press
   `Ctrl+Shift+V`.
5. Expect: the buffer is saved, a task terminal runs
   `bgraph watch <file> --open --port 0`, a free loopback port is chosen, the
   default browser opens on `http://127.0.0.1:<port>`, and every later save
   reloads the drawing. `Ctrl+C` in that terminal stops it. If the browser
   does not open, the terminal keeps the URL.
6. Optional but recommended: **task: spawn → bgraph: Preview** once, without
   the shortcut, to confirm the task itself works before blaming the keymap.
